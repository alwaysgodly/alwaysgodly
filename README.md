**🫁 Tuberculosis Detection using ML** &nbsp;|&nbsp; [GitHub](https://github.com/alwaysgodly/Tuberculosis-Detection) &nbsp;|&nbsp; 🏅 **Patent Published — No. 202521021220A**

> Deep CNN model for automated TB detection from chest X-rays. Research published as a patent.

- 🧠 95%+ accuracy · 93% precision · 94% recall on chest X-ray classification
- 🔬 Image preprocessing pipeline — resizing, normalization, augmentation
- 🌐 Deployed via Flask REST API with real-time image upload and prediction interface

`Python` `TensorFlow` `Keras` `CNN` `OpenCV` `Flask`

---

**🔗 Federated Learning — Privacy-Preserving Distributed ML** &nbsp;|&nbsp; [GitHub](https://github.com/alwaysgodly/federated-learning-project)

> Complete federated learning system — collaborative model training without sharing raw data. GDPR & HIPAA compliant.

- 📈 77.5% accuracy (+67.5% improvement over 10 rounds) across 5 clients
- ⚡ 260% more bandwidth-efficient than centralized ML — raw data never leaves devices
- 🔒 SHA-256 checksums · Differential Privacy (Laplace noise) · malicious update detection
- 🌐 3 interactive web demos: Healthcare (HIPAA) · Finance (GDPR) · Mobile Keyboard

`Python` `FedAvg` `Flask` `Differential Privacy` `SHA-256`

---

**📦 SupplyChainEnv — RL-Based Supply Chain Optimization** &nbsp;|&nbsp; [GitHub](https://github.com/alwaysgodly/meta-scaler) &nbsp;|&nbsp; [🤗 Live on HuggingFace](https://huggingface.co/spaces/alwaysgodly/supplychain)

> Real-world Reinforcement Learning environment for supply chain restocking, built on the OpenEnv framework. Live on HuggingFace Spaces.

- 🏭 3 difficulty levels · up to 3 warehouses · 10 products · noisy seasonal demand + supplier delays
- 🎯 Baseline scores: Easy 0.568 → Medium 0.421 → Hard 0.345
- 🐳 Full Docker support · REST API (reset/step/state) · reproducible evaluation

`Python` `Reinforcement Learning` `OpenEnv` `FastAPI` `Docker` `HuggingFace`

---

**🧿 OpenD — Decentralized NFT Marketplace on Internet Computer** &nbsp;|&nbsp; [GitHub](https://github.com/alwaysgodly/OpenD-NFT-Marketplace-on-Internet-Computer)
